# Obscura🎬
Obscura - это приложение для знакомства киноманов, основанное на мэтчинге по любимым фильмам.

## 🚀 Возможности
- Регистрация и аутентификация
- Создание профиля (имя, возраст, раздел "о себе", фотографии, любимые фильмы)
- Возможность ранжировать других пользователей по возрасту 
- Просмотр карточек других пользователей и свайп их по системе "лайк/дизлайк"
- Чат после возникновения мэтча (взаимной симпатии)
> ⚠️ Для доступа к базе фильмов в приложении используется внешний API (Open Movie DB). К сожалению, подписка, позволяющая полноценно использовать базу фильмов, утеряна. Для демонстрации корректной работы приложения добавлены видео и скриншоты.

## 🛠️ Стек и архитектура
- **Язык:** Swift  
- **UI:** UIKit + SnapKit (верстка кодом)  
- **Архитектура:** MVVM + сервисный слой
- **Сеть:** URLSession
- **Бэкенд:** Firebase (Firestore, Auth, Storage)  
- **Чат:** MessageKit + InputBarAccessoryView  
- **Кеш изображений:** SDWebImage  
- **Зависимости:** CocoaPods  

## 🚀 Установка и запуск
1) Клонируйте репозиторий

```bash
$ git clone https://github.com/ilyaberous/CinephileDatingApp.git
```

2) Перейдите в папку склонированного репозитория

```bash
$ cd CinephileDatingApp
```

3) Установите Podfile

```bash
$ pod install
```

4) Откройте .xcworkspace файл

```bash
$ open CinephileDatingApp.xcworkspace
```

5) Скомпилируйте и запустите приложение

6) Готово!
